## 2. Design direction — "Warm Spa"

One calm, modern, hotel-bathroom scheme. Keeps the existing plumbing positions
(shower / basin / WC all stay put) to control cost, while replacing every
visible surface and fitting.

| Element | From → To |
|---|---|
| **Wall tile** | White + navy diamonds → large-format (600×300) warm off-white / soft marble-effect porcelain, run continuously, **no borders or diamonds** |
| **Feature wall** | Grey half-wall → single full-height **fluted/ribbed** or marble feature behind the vanity |
| **Floor** | Blue-diamond tile → large-format stone-effect porcelain over **electric underfloor heating** |
| **Shower screen** | Framed aluminium sliders → **frameless or matte-black-framed** walk-in glass panel |
| **Shower valve** | Chrome riser → **brushed-brass thermostatic** with fixed rainfall head + handset |
| **Basin** | Pedestal → **wood-tone vanity unit** with countertop basin (adds storage) |
| **WC / bidet** | Twin units → modern **back-to-wall WC**; remove bidet to free space (or fit a bidet-seat) |
| **Brassware** | Mixed chrome → unified **brushed brass / gold** throughout (taps, rail, valve, handles, roll holder) |
| **Mirror** | Plain → **backlit / illuminated** anti-fog mirror |
| **Lighting** | Single fitting → recessed warm-white (3000K) spots + mirror light + LED niche strip + quiet extractor |
| **Warmth** | Cold grey-white → timber vanity, greenery, textured textiles |

**Accent metal:** brushed brass (warmer, more "spa"). Matte black is the
alternative if you prefer a sharper, more contemporary look.

## 3. Concept mapped to each photo

**Photo 1 — wide view from the door**
Floor becomes large stone-effect porcelain with UFH; the busy diamond tiles
disappear into one continuous warm-white wall. The pine door is refinished (or
replaced) in a warm oak tone to tie into the new vanity.

**Photo 2 — basin / shower / WC corner**
Pedestal basin → timber vanity + countertop basin + brushed-brass tap and
backlit mirror. Aluminium shower frame → frameless glass. Chrome taps → brass.

**Photo 3 — towel rail & shower screen**
Chrome ladder rail → tall brushed-brass towel radiator. Framed sliders →
slim matte-black or frameless screen. Grout lines minimised with larger tiles.

**Photo 4 — door wall & WC**
Navy diamond band removed; WC becomes a clean back-to-wall unit; brushed-brass
roll holder. Optional: fluted-wood feature panel on this wall for warmth.

**Photo 5 — shower interior & window**
Inside the cubicle: rainfall head, recessed niche with LED strip, large-format
tile to ceiling; frosted window retained but reframed to match.

## 4. Full-renovation budget (GBP)

Two specs within "full renovation." Assumes a ~2.0 × 2.5 m room (~5 m² floor,
~22–26 m² of wall to tile). **Supply & fit**, mid-2026 UK rates. Figures are
planning estimates — get 2–3 local quotes to firm up.

| # | Line item | Standard (£) | Premium (£) |
|---|---|---:|---:|
| 1 | Design / setting-out | 0–150 | 200–400 |
| 2 | Strip-out & waste disposal | 400 | 700 |
| 3 | First-fix plumbing & electrics | 900 | 1,500 |
| 4 | Plastering / boarding & **tanking** | 600 | 1,000 |
| 5 | Tiles — supply (wall + floor) | 1,000 | 2,000 |
| 6 | Tiling — labour | 1,100 | 1,700 |
| 7 | **Underfloor heating** (electric mat + stat) | 350 | 600 |
| 8 | Walk-in shower screen | 450 | 900 |
| 9 | Shower valve + rainfall + handset | 350 | 750 |
| 10 | Back-to-wall WC (+ remove bidet / make good) | 350 | 700 |
| 11 | Vanity unit + countertop basin + tap | 450 | 1,000 |
| 12 | Heated towel rail | 180 | 400 |
| 13 | Backlit anti-fog mirror | 180 | 380 |
| 14 | Lighting (spots, LED strip, extractor) | 300 | 600 |
| 15 | Brassware & accessories set | 220 | 450 |
| 16 | Decorating / paint & sundries | 200 | 350 |
| 17 | General fitting labour (5–10 days) | 1,200 | 2,200 |
| | **Subtotal** | **8,180** | **15,630** |
| | Contingency (~10%) | 820 | 1,570 |
| | **TOTAL (est.)** | **≈ £9,000** | **≈ £17,200** |

**Notes**
- Removing the bidet saves a fitting but adds a make-good cost — netted into #10.
- Keeping all plumbing in its current position is the single biggest saving;
  moving the WC or shower drain would add £500–£1,500.
- Premium column = better tiles, frameless screen, branded brassware,
  wall-hung WC with concealed frame.
